Mocha Poker shuffle verifier

Every deck at a Mocha Poker table is fixed by a secret server seed and by seeds that the players’ browsers add. This page re-does the shuffle from those seeds and tells you whether it gets the same deck. It does not talk to the site, and the code is short enough to read: verify.js.

    Check hands

    In the app, open History and press Copy fairness data (or Download all hands), then paste it here or choose the file. One hand, a list of hands, or a whole session all work.

    What does “✓” mean?

    The server committed to a hash before the hand. After the hand it revealed the seed behind that hash. If the hash matches and the deck comes out the same, the server could not have picked the cards after seeing anyone’s seed. To be sure the hash is the one you saw before the deal, compare the commitment shown for each hand with what your table displayed, or rely on the copy your own browser stored (included in the export as youSaw). The full rules are in FAIRNESS.md.
